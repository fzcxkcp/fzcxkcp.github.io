HTML Structure Demo

HTML 结构页

这个示例只强调结构。最常见的几个标签：`header`、`main`、`section`、`article`、`aside`、`footer`。

主内容区

主内容通常放在 `main` 里，再根据内容继续拆 `section` 或 `article`。

文章卡片

如果这一块本身就是相对独立的一条内容，常见写法就是 `article`。

侧边信息

侧边栏适合放补充说明、导航、标签或推荐入口。
