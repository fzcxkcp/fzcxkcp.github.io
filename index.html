reuse&rules

几个命令

  • 能够使用Markdown，但是需要有frontmatter才会被推送

基础语法规则

  1. 文件位置: source/_posts/文章名.md
  2. 编码格式: UTF-8（必须）
  3. 换行: 两个空格+回车 或 空一行

Frontmatter 详解（YAML格式）

日期识别规则

  • date: 创建时间，决定文章在列表中的排序
  • updated: 最后修改时间，用于显示”更新于X天前”
  • 格式: YYYY-MM-DD HH:mm:ss 或 ISO 8601

分类 vs 标签

内容书写规范

摘要设置

图片引用（关键）

图片实际存放位置对应：

  • 方式1: source/images/pic.png → /images/pic.png
  • 方式2: source/_posts/文章名/pic.png → 与文章关联

特殊标签

发布流程检查清单

  • Frontmatter 包含 title 和 date
  • 文件保存为 .md 格式，UTF-8 编码
  • 图片已放入 source/images/ 或相对路径
  • 本地预览正常 (hexo s)
  • 执行 hexo clean && hexo g && hexo d

避坑指南

  1. 文件名不要用中文（会导致URL乱码），用英文或拼音

    • 坏: 2026-04-16-我的第一篇博客.md
    • 好: 2026-04-16-my-first-post.md

  2. 冒号后必须有空格（YAML语法）

    • 坏: title:我的文章
    • 好: title: 我的文章

  3. 时间不能是未来，否则文章不会显示

  4. 特殊字符转义: 标题含冒号、井号等需用引号包裹

  1. 多个分类不要混用语法
