Datacore HomePage

把 Obsidian 首页做成真正可用的工作台

datacore-HomePage 是围绕 Obsidian Datacore 构建的主页式展示页面。它不只是把数据列出来，而是把常用信息、入口、卡片和内容组织成一个可浏览、可点击、可长期维护的主页系统。

定位
Datacore 驱动的主页页面
面向个人主页、知识导航、项目入口和内容聚合场景。
关键词
主页 / 卡片 / 数据聚合
通过 HTML 页面与 Markdown 页面一起发布，既可展示，也方便继续写作与维护。

它解决什么问题

普通笔记首页往往只有静态链接，datacore-HomePage 更适合做成“项目门面”：让访问者先看到统一介绍，再继续进入具体页面、文章或说明文档。

它适合放什么

  • 插件主页与功能总览
  • 知识库项目入口与导航页
  • 作品列表与版本说明入口

当前这套发布方式

入口页负责第一屏展示，介绍页负责完整说明，Markdown 页面负责把内容纳入 Hexo 正常页面流，三者职责分离，后续维护更轻。

为什么单独做一个 HomePage 介绍页

因为入口页只适合展示“是谁、去哪里”，不适合塞太多说明。把 datacore-HomePage 作为独立介绍页后，入口页仍然干净，点进去以后又能完整讲清楚产品定位、用途和结构，这样更像一个真正能被外部访问的项目主页。
