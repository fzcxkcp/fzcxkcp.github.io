Component System

它不是一块首页皮肤，而是一套可以拖拽、筛选、嵌入、组合的 Datacore 工作面。

`datacore-home` 现在已经形成了以浏览、搜索、动作入口、时间节律、内容承载、个人面板为主轴的首页系统。 重点不在“把信息摆上去”，而在于让首页具备检索、切换、筛选、排序与继续打开笔记的能力。

真实模块来自 `HomePage-core.md` 支持画布排布、缩放、自动保存 组件之间不是孤立展示
